プライバシーポリシー

開発メモ · 2026年11月2日 制定

開発メモ(以下「本アプリ」)は、メモと作業時間の記録のためのアプリです。ブラウザ版(https://noneedsgames-ui.github.io/worklog-memo/)と Android アプリ版があります。本アプリが扱う情報と、その扱い方を次のとおり定めます。

1. 扱う情報

  • 利用者が書いたメモ、ボードの配置、予定、収支、長期計画、タイマーの記録、設定
  • 本アプリを開いていた時間
  • Android アプリ版で、利用者が選んだアプリの使用時間(「使用状況へのアクセス」を許可した場合のみ)と、端末に入っているアプリの名前の一覧(利用者がアプリを選ぶときのみ)
  • 「ドライブで同期」を使う場合、Google アカウントのメールアドレス(同期の画面に表示するためだけに使います)

2. 保存する場所

上の情報は、利用者のブラウザ(ブラウザ版)または端末(Android アプリ版)の中に保存します。開発者のサーバーはありません。開発者やほかの第三者に、これらの情報を送ることはありません。

3. Google ドライブとの同期

利用者が設定の「ドライブで同期」で Google アカウントにログインした場合に限り、本アプリは Google ドライブの API を使い、利用者自身の Google ドライブの、本アプリ専用の隠しフォルダ(アプリデータ フォルダ)に、上の情報をまとめたファイルを一つ置いて読み書きします。これにより、ブラウザ版・Android アプリ版・別の端末で、同じデータを使えます。

  • 本アプリが求める権限は https://www.googleapis.com/auth/drive.appdata だけです。本アプリは、利用者のドライブにあるほかのファイルを見ることも、変えることもできません。
  • Google から受け取った情報は、同期のためだけに使い、開発者やほかの第三者には渡しません。広告や分析にも使いません。
  • ログインの鍵(アクセストークン)は、ブラウザ版ではそのブラウザの中に最長1時間保存し、Android アプリ版では端末の Google の仕組みが管理します。

本アプリによる Google API から受け取った情報の利用と他のアプリへの移転は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

4. 情報の削除

  • 本アプリの「設定 › このアプリについて › すべてのデータを消す」で、そのブラウザまたは端末の情報を消せます。Android アプリ版は、アンインストールしても端末の情報が消えます。
  • ドライブに置いた同期のファイルは、Google ドライブのウェブ版で「設定 › アプリを管理」を開き、本アプリの「オプション › 隠しアプリデータを削除」で消せます。
  • 本アプリへの Google アカウントの許可は、本アプリの「同期をやめる」か、Google アカウントの「セキュリティ › サードパーティ製のアプリとサービス」で、いつでも取り消せます。

5. Android アプリ版の権限

通知・アラーム・再起動の知らせの受信は、タイマーと予定の知らせに使います。使用状況へのアクセスと、他のアプリの上に重ねて表示は、利用者が選んだアプリの使用時間の表示と、集中タイマー中の覆いに使います。インターネットは、「ドライブで同期」にだけ使います。どの権限も、端末の設定でいつでも外せます。

6. 変更

このポリシーを変えるときは、このページを書き換えて知らせます。
