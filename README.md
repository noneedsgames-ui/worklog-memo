# 作業記録メモ帳(ブラウザ版)

メモ・ボード・タイマー・作業時間の記録・予定・収支・長期計画を、ひとつにまとめたメモ帳です。
ブラウザで開くだけで使えます。

**開く:** https://noneedsgames-ui.github.io/worklog-memo/

- 入力したものは、開いたブラウザの中に保存します。開発者には送りません。
- 設定の「ドライブで同期」で Google アカウントにログインすると、あなたの Google ドライブの、このアプリ専用の隠しフォルダを通して、Android アプリ版や別の端末と同じデータを使えます。
- 別の端末やブラウザへ移すときは、「設定 › データの引っ越し」で書き出して読み込んでください。
- ブラウザを替えたり、サイトのデータを消したりすると、中身も消えます。ときどき書き出しておくと安心です。

このリポジトリの `index.html` は、開発用のリポジトリから写したものです。
